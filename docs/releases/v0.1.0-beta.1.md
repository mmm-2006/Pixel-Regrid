# Pixel Regrid v0.1.0-beta.1

首个 Windows x64 JavaScript 桌面预发布版。

## 功能

- 自动识别像素色块网格，将 AI 生成的伪像素画还原为规则像素网格。
- 最近邻、结构保护、k-centroid 三种缩放算法。
- 主体裁边、等比例缩放、保留主体大小与透明画布调整。
- 并排预览、缩放、像素网格、批量导出、取消和重名输出保护。
- Python 版保留在源码中，作为独立处理实现与对照。

## 下载与运行

下载 `PixelRegrid-v0.1.0-beta.1-windows-x64-js.zip`，解压后双击 `PixelRegrid-JS.exe`。
需要 Windows x64 与 Microsoft Edge WebView2 Runtime，无需安装 Python 或 Node.js。
校验文件为 `SHA256SUMS.txt`，可用 PowerShell `Get-FileHash -Algorithm SHA256` 核对。

程序正常图片处理不上传图片，源文件保留。默认输出到原图旁的 `perfect_pixel_output/`。

## 已知限制

- JavaScript 首次网格识别目前比 Python/NumPy 实现慢；同图改尺寸可复用缓存。
- 限色、结构保护和 k-centroid 的部分结果与 Python 实现不同。
- 自动网格识别上限为 400 万像素，直接转换读取上限为 3200 万像素。
- 外部修改原图后，应从列表移除并重新导入。
- 本地验证未覆盖干净 Windows 虚拟机、全部图片格式或所有系统文件操作。

测试记录见 [发布验证](../RELEASE_VALIDATION.md)。此版本按预发布提供，欢迎反馈输入图片、参数和复现步骤。
