# Pixel Regrid v1.0.0

将 AI 生成的伪像素画还原为规则像素网格，支持像素缩放、画布调整与批量导出。

## 功能

- 自动识别像素网格，支持中心、中位数和多数色取样。
- 最近邻、目标像素、k-centroid 三种缩放算法；目标像素细节保护默认关闭。
- 主体裁边、等比例缩放、透明画布调整。
- 并排预览、默认开启像素网格、批量导出及重名输出保护。
- 网页版支持手机操作，图片在本地处理。

## 下载与运行

下载 `PixelRegrid-v1.0.0-windows-x64-js.exe`，双击运行。
需要 Windows x64 与 Microsoft Edge WebView2 Runtime，无需安装 Python 或 Node.js。
项目及第三方许可已内置，在“帮助 → 许可与第三方声明”查看。
默认输出到原图旁的 `perfect_pixel_output/`，原图保留。

[在线使用](https://mmm-2006.github.io/Pixel-Regrid/) · [项目仓库](https://github.com/mmm-2006/Pixel-Regrid)

## 已知限制

- 自动网格识别需要清楚、一致的色块网格，最多处理 400 万像素。
- 限色、结构保护和 k-centroid 的部分结果与 Python 实现不同。
- 外部修改原图后，应从列表移除并重新导入。

Python 实现保留在源码中。欢迎通过 GitHub Issues 反馈图片、参数和复现步骤。
